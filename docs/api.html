class Image Abstract

Declared in Image.h  ·  Implemented in Image.cpp

Abstract base class for all image types. Holds shared state (dimensions, pixel data, checksums) and declares the pure-virtual interface that every concrete subclass must implement.

Static Methods

static int run(const std::string& arg1, const std::string& arg2)

Program driver and simple factory. Reads the magic-number header of arg1 to determine the image format, constructs the appropriate concrete subclass for both arguments, and executes the current operation (correlation).

param arg1 — path to the first image file

param arg2 — path to the second image file

returns 0 on success, -1 on failure

static std::string getInputFormat(const std::string& filename)

Opens filename, reads the first token (magic number), and returns it as a string.

returns Magic number string, e.g. "P1", "P2", "P3", or empty string on error

Virtual Methods

virtual int loadImage(const std::string& filename) = 0

pure virtual Load image pixel data from filename into imageData. Each subclass validates the format header and fills rows, cols, maxPossibleVal, actualMaxVal, actualMinVal.

returns 0 on success, -1 on any error

virtual int regularize() = 0

pure virtual Normalize pixel intensities to span the full 0–255 range using min-max rescaling.

returns 0 on success, -1 on failure

virtual int convertToBinary() = 0

pure virtual Convert pixel data to binary representation (0 or 1). Threshold depends on the source format (127.5 for grayscale, 382.5 for RGB).

returns 0 on success, -1 on failure

virtual int convertToGrayscale() = 0

pure virtual Convert pixel data to a single-channel grayscale representation.

returns 0 on success, -1 on failure

virtual int convertToRGB() = 0

pure virtual Convert pixel data to a three-channel RGB representation.

returns 0 on success, -1 on failure

Non-virtual Methods

int computeRowChecksums()

Fills rowChecksumVec with the sum of pixel intensities in each row.

returns 0 on success

int computeColChecksums()

Fills colChecksumVec with the sum of pixel intensities in each column.

returns 0 on success

int writeRowChecksum(const std::string& filename)

Writes rowChecksumVec contents to filename, one value per line.

returns 0 on success, -1 if file cannot be opened

int writeColChecksum(const std::string& filename)

Writes colChecksumVec contents to filename, one value per line.

returns 0 on success, -1 if file cannot be opened

int writeImage(const std::string& filename)

Writes the current image data to filename in the appropriate Netpbm format.

returns 0 on success, -1 on failure

bool imageFileIsValid(const std::string& filename)

Validates that filename is a well-formed Netpbm image: magic number, valid header fields, correct pixel count, and values within declared range.

returns true if valid, false otherwise (error written to stderr)

bool providedFilesAreValid(const std::string& rowFile, const std::string& colFile)

Validates that rowFile and colFile are well-formed checksum files matching the current image dimensions.

returns true if both files are valid

class ColorImage : public Image

Declared in ColorImage.h  ·  Implemented in ColorImage.cpp  ·  Format: P3

int loadImage(const std::string& filename) override

Parses a P3 PPM file. Validates the magic number (P3), reads width/height/max-value header fields, then reads each pixel as an RGB triplet. Updates actualMinVal and actualMaxVal.

returns 0 on success, -1 on parse error

int regularize() override

Applies min-max rescaling to every channel of every pixel: newVal = (oldVal - min) × 255 / (max - min). Uses std::round to produce integer results.

returns 0

int convertToBinary() override

Replaces each pixel with 1 if pixelSum() > 382.5, else 0. Threshold is half of the maximum possible RGB sum (3 × 255 / 2).

returns 0

int convertToGrayscale() override

Replaces each pixel with a single-channel value equal to (R + G + B) / 3.

returns 0

class GrayscaleImage : public Image

Declared in GrayscaleImage.h  ·  Implemented in GrayscaleImage.cpp  ·  Format: P2

int loadImageFast(const std::string& filename)

Optimised loader. Reads the entire file into a std::string, wraps it in an std::istringstream, then tokenises. Validates P2 header and pixel values. Significantly reduces system-call overhead compared to line-by-line reading.

returns 0 on success, -1 on parse error

int loadImage(const std::string& filename) override

Delegates to loadImageFast().

returns result of loadImageFast()

int regularize() override

Applies min-max rescaling to the single intensity channel of every pixel.

returns 0

int convertToBinary() override

Thresholds at 127.5: pixels with intensity > 127.5 become 1, all others become 0.

returns 0

int convertToRGB() override

Copies the single intensity value to all three RGB channels (produces a grey-toned RGB image).

returns 0

static int correlation(const GrayscaleImage& img1, const GrayscaleImage& img2)

static Computes the Pearson correlation coefficient between two grayscale images. Validates that both images have identical dimensions. Detects and rejects NaN results. Prints the result to stdout.

param img1 — first grayscale image (const reference)

param img2 — second grayscale image (const reference)

returns 0 on success, -1 if dimensions differ or result is NaN

static double getAverageIntensity(const GrayscaleImage& img)

static Computes the mean pixel intensity across all pixels in img. Accepts a const reference to avoid an expensive copy on large images.

returns mean intensity as a double

class BinaryImage : public Image

Declared in BinaryImage.h  ·  Implemented in BinaryImage.cpp  ·  Format: P1

int loadImage(const std::string& filename) override

Parses a P1 PBM file. Validates magic number, header fields (max-value must equal 1), and that every pixel is exactly 0 or 1.

returns 0 on success, -1 on parse error

int regularize() override

No-op. Binary images are already in their final range {0, 1}.

returns 0

int convertToGrayscale() override

Maps each pixel: 0 → 0, 1 → 255 (multiply by 255).

returns 0

int convertToRGB() override

Maps each pixel to RGB channels: 0 → (0,0,0), 1 → (255,255,255).

returns 0
