What is Image Processor?

An academic C++ project that evolved through 7 development assignments

Image Processor is a command-line C++ application that reads, validates, transforms, and analyses digital images stored in the portable bitmap family of formats (PBM, PGM, PPM). Built without any external image libraries, it relies entirely on the C++ Standard Library and demonstrates core object-oriented design patterns such as polymorphism and inheritance.

📌 Current Capability The latest build computes the Pearson correlation coefficient between two grayscale images — a real-world metric for measuring how similar two images are pixel by pixel.

Key Features

Everything you can do with the library today

🎨

Multi-Format Support

Read and write RGB (.ppm), Grayscale (.pgm), and Binary (.pbm) images in Netpbm format.

📊

Pearson Correlation

Compute the correlation coefficient between two grayscale images — values range from -1 (inverse) to 1 (identical).

🔄

Format Conversion

Convert between RGB, Grayscale, and Binary via virtual polymorphic methods on the shared Image base class.

⚖️

Image Normalization

Regularize pixel intensities to the full 0–255 range using min-max rescaling on each channel.

✅

Checksum Analysis

Generate and compare per-row and per-column checksums to verify image integrity and detect corruption.

🚀

Optimized Performance

Valgrind-profiled and optimized loading path reduces instruction count by ~3% on 1920×1080 images.

🔍

Thorough Validation

Every input file is validated: magic number, header fields, pixel values, and file-length consistency.

📝

Doxygen Documented

All classes and methods carry Doxygen-compatible comments; run doxygen Doxyfile to generate a full HTML reference.

Quick Start

Up and running in three commands

  1. Clone the repository

    git clone https://github.com/Andy-Borch/Image-Processor.git
cd Image-Processor

  2. Build the executable

    make ImageProcessor

  3. Run with two grayscale images

    ./ImageProcessor image1.pgm image2.pgm
# → Prints Pearson correlation coefficient, e.g. 0.9982

Architecture at a Glance

Five classes, one clear inheritance hierarchy

Image   (abstract base class)
├── ColorImage     RGB / PPM (P3)
├── GrayscaleImage  Grayscale / PGM (P2)
└── BinaryImage    Binary / PBM (P1)

Pixel   (standalone value type — RGB · Grayscale · Binary)

The Image base class holds all shared state (dimensions, pixel data, checksums) and declares pure-virtual methods (loadImage, regularize, convertToBinary, convertToGrayscale, convertToRGB) that each subclass overrides with format-specific logic.
